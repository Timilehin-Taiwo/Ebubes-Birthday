HOST ON GITHUB PAGES
1. Create a new GitHub repository (public or private with Pages enabled).
2. Upload index.html, the audio folder and .nojekyll to the root of the repo.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. After a minute your site is live at https://YOUR-USERNAME.github.io/REPO-NAME/

EDITING (your private edit mode)
- Open the live site (or the file) and add #edit to the address.
- Write your messages, photos and voice notes, then tap Export.
- Rename the exported file birthday-site.html to index.html and upload it, replacing the old one.
